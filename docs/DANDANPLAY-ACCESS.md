# 弹幕应用接入与诊断

本衍生项目已接入维护者获批的弹弹play应用授权。20395 的节目搜索和弹幕获取接口均验证为 HTTP 200，用户已反馈授权包测试成功；20396 保留同一授权配置，仅清理显示名称。当前发布验证见 [20396记录](RELEASE-20396-VERIFICATION.json)。上游历史文档中的设备验收与版本结论不直接代表本项目。

诊断顺序：确认既有合法配置及字段存在（仅布尔值）→检查正常构建是否使用`--dart-define-from-file=<受保护JSON>`→核对实际APK身份→看自动/手动接口状态及可见弹幕。不要打印secret或完整认证头。若仍403，按官方错误类别核对时钟/应用状态/签名，不绕过认证，不因一次状态码推断所有历史原因。

私有配置源文件与构建凭据留在受控环境，不能加入源码或公开附件。客户端二进制注入不保证秘密不可提取，分发范围须符合应用授权。
